# 💲 Sell System

A custom inventory-based selling system designed for Minecraft servers. Players can sell items through an intuitive GUI, while server owners have full control over item values through configurable files.

## ✨ Features

- Sell items through a custom inventory GUI
- Supports selling multiple items at once
- Live calculation of total sell value
- Configurable prices using YAML files
- Supports item categories
- Easy to expand with new items
- Economy integration
- Player-friendly interface

## 🎮 How It Works

Players open the Sell GUI and place any sellable items into the inventory. As items are added or removed, the total value updates automatically. When the player confirms the sale, the items are removed and the money is deposited into their balance.

## ⚙️ Configuration

The system is designed to be easy to configure.

- Item prices are stored in YAML files.
- Categories can be organised separately.
- New items can be added without editing the core Skript.
